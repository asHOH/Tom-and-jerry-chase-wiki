# 物体

> 随着对游戏内容和数据的深入研究，本文所述内容可能会发生变化，请以最新内容为准。  
> 编写者：音乐家杰瑞  
> 最后编辑时间：**20261031**

**物体**（也被称作**实体**、**单位**、**对象**等）是游戏内参与各类互动的最小单位。 游戏中存在多种多样的物体，例如**角色、道具、场景物**等。

**单一物体**具有如下特征：

- **独立存在**：单一物体无法再往下解析和细分，作为一个整体参与互动。
- **可互动**：物体之间可以彼此产生影响。

> 部分物体具有**衍生**其它内容的能力，对于这种情况：若被衍生出的部分能够**独立存在**且能够**与其它物体互动**，则将衍生出的物体归类为[衍生物](/entities)；其余情况则根据玩家游戏习惯，将其视作**其它物体的一部分**或也归类为**衍生物**。

## 物体的分类

在本网站中，物体按如下标准进行分类。

- **角色**：包括可被玩家在局外获取，并在大多数模式中自由选择的[猫角色](/cat)和[鼠角色](/mouse)。截至本文更新时（2026.10.31），游戏中共有**21**位猫角色和**35**位鼠角色。

> _游戏内除常规的猫/鼠角色外，还存在一些特殊角色（例如由魔术师召唤的[兔子先生](/entities/兔子先生)，由地图自带的[小黄鸭](/fixtures/小黄鸭)等），这些角色同样具有常规角色所具有的全部或部分性质。我们根据具体内容和游戏习惯，将其归入了下文所述的其它板块。_

- **道具**：指会在游戏中自然（或在特定场景/条件下）刷新的各类常规物体，与地图结构不深度绑定，刷新具备一定的随机性。
- **地图组件**：又名**场景物**、**组件**，指参与构成地图结构的各类物体，与地图结构深度绑定，随机性低（仅部分内容可能具有较小范围的随机性），大多在模式与地图决定时就会确立自身数量和位置。
- **衍生物**：由其它物体衍生出的新物体，通常不会自然存在于游戏中。（游戏内并无衍生物的概念。根据各自的特性，衍生物实际可能归属于角色、道具或地图组件。此处创建该概念仅用于精准细分游戏内容）

> _对于部分难以界定归属的物体，我们根据玩家的游戏习惯进行了归类。例如：火箭、奶酪、狗骨头等被归入道具，老鼠洞、墙缝等被归入场景物。_

## 物体的属性

物体自身的特质被称作它的**属性**（包括碰撞大小、受重力大小，角色的移速、跳跃速度等）。  
属性又可分为**基础属性**和**实际属性**。

- **基础属性**：某个物体由数据文件直接定义的属性基本值，不同物体的基础属性不同。
- **实际属性**：某个物体在实际游戏中的实时属性值，会受实时效果影响，随游戏进程不断变化。

某些属性有特殊的计量单位，其具体定义详见各自的相关板块。  
部分属性具有多个单位，下表列出了它们的相关换算关系。

| **类型** | **网站单位** | **官方单位** | **换算关系**   |
| -------- | ------------ | ------------ | -------------- |
| 长度     | (单位长)     | 米           | 32单位长 = 1米 |
| 推速     | %/秒         | 点           | 5%/秒 = 1点    |

您可以在各物体的对应词条界面查看其基础属性。

> 游戏中可以在角色页面查阅角色的“属性点数”，但**该内容与角色基础属性并无关系**，请注意。

## 物体的特性

物体的功能/作用各异。不同物体之间的作用可能有冲突，某些物体在某些情况下的实际效果可能与预期不符，此类情况被称作该物体的**特性**。  
您可以在物体的对应界面，或是特性大全界面查看本网站已收录的全部特性。

## 进阶\*：物体之间的互动

物体之间存在各式各样的互动关系，常见的有以下几种：

- **碰撞**：物体接触后彼此碰撞，互相产生斥力，改变彼此轨迹。
- **无视碰撞**：物体接触但对彼此不产生影响，继续按各自轨迹运动。
- **拾取/被拾取**：角色可通过道具键拾取部分道具或类似物体，将其储存在道具/药水栏。随后，可通过对应键位将其投掷/使用/原地放置。
- **交互**：角色与可交互物体接触时，可通过交互键与其互动。

> _因部分原因导致两个会互相碰撞的物体的模型重叠时，彼此会持续产生斥力，直到模型不再重叠为止。_

> _部分\***\*投掷物、投射物\*\***被投掷后与特定对象产生碰撞时，会产生特殊效果，这被称之为\***\*命中\*\***。_

> _部分\***\*由非玩家操作的角色（包括特殊角色）\*\***也可拾取物体或与物体进行交互，不过，它们绝大部分时候只会进行规定的几种行为。某些情况下可以通过重叠多个可交互物体的方式，让NPC执行优先级较高的交互，以此观察到部分特性_。

## 进阶\*：角色的载体特质

**角色**具有**载体**特质，可以承载**状态、技能、特效**等内容，这些内容会产生不同**效果**，有时也会改变其**属性或特性**。

### 状态

**状态**指的是**仅能对角色（含特殊角色）施加**的，可**改变其属性**或**产生特殊效果**的一类内容。  
角色可以获得多个状态，不同状态之间**独立结算**，重复获得时将刷新持续时间（除非有特别说明），且若对应状态“可叠加”则会叠加一层。  
有关更进一步的介绍，可查阅[状态相关机制](/mechanics/buff)。

### 技能

**技能**指的是**仅角色（含特殊角色）可获得**的，通过角色行为**主动或被动触发**，随后**产生特殊效果**的一类内容。  
“**技能**”有两个涵盖范围不同的定义。狭义上的技能只包括角色的**主动、武器、被动技能**，以及因特定条件而获得的**特技、额外技能**等；广义上的技能则包括**任何在本质上属于“技能”的内容**，包括但不限于**知识卡、角色的隐藏派生技能**等。此处讨论的为广义上的技能。  
角色可以获得多个技能，各个技能之间彼此**独立结算**。应用同一个键位的“可主动释放”类的技能，新获得的技能会覆盖老技能的键位（例如[雪梨](/characters/%E9%9B%AA%E6%A2%A8)的远程治疗及花束传送），虽然两个技能本质上均未消失，但只有失去新技能后才能释放老技能。  
有关更进一步的介绍，可查阅[技能相关机制](/mechanics/skill)。

### 特效

**特效**包括**视觉特效**与**音效**两部分，用于丰富游戏表现力，以及在部分情况下起到提示作用。  
“特效”本身并无作用，不过大多数特效直接或间接来自角色身上的相关状态，这导致特效同样能用于提示对应状态的存在，但二者并无绝对关联。
